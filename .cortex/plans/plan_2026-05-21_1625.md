## Multi-Turn Conversation Implementation

### Context

Currently, `call_agent()` sends only the latest user message:
```python
"messages": [{"role": "user", "content": [{"type": "text", "text": question}]}]
```

The agent has no memory of previous questions. Each call is stateless.

### Approach: Pass Full Conversation History in Messages Array

Per the DATA_AGENT_RUN docs: "If thread_id and parent_message_id are NOT passed, messages includes the conversation history and the current message."

We'll pass the full chat history (user + assistant messages) in the `messages` array on every call. The agent will see the full context and can handle follow-ups like "break that down by rep" or "what about Mid-Market?"

**Why not Threads API?** Threads require the REST API to create threads and track message IDs. The SQL function `DATA_AGENT_RUN` supports threads but we'd need to manage thread creation separately. The messages-array approach is simpler, works entirely through the SQL function, and keeps all state in Streamlit session_state.

### Implementation Steps

1. **Modify `call_agent()`** to accept the full message history and append the new question
2. **Build the messages array** from `st.session_state.messages` — converting our stored messages into the API format (user messages as `{"role": "user", "content": [{"type": "text", "text": "..."}]}`, assistant messages as `{"role": "assistant", "content": [{"type": "text", "text": "..."}]}`)
3. **Add a "Clear conversation" button** in the sidebar so users can reset context
4. **Limit history length** to prevent token overflow — keep the last 10 exchanges (20 messages)

### Key Change in `call_agent()`:

```python
def call_agent(question: str, history: list) -> dict:
    messages = []
    for msg in history:
        if msg["role"] == "user":
            messages.append({"role": "user", "content": [{"type": "text", "text": msg["content"]}]})
        elif msg["role"] == "assistant":
            messages.append({"role": "assistant", "content": [{"type": "text", "text": msg["content"]}]})
    # Add the new question
    messages.append({"role": "user", "content": [{"type": "text", "text": question}]})
    
    request_body = json.dumps({"messages": messages})
    # ... rest of the call
```
